Info diagram demos

The info diagram is a minimal built-in type: it renders a single line of text with the Mermaid version bundled in this page’s script. It is useful for smoke tests, E2E checks, and confirming which build you are running.

There is no title, shape, or layout to customize. Optional keyword showInfo is accepted by the grammar but does not change the SVG; both forms below should look identical.

Supported syntax

info
Minimal definition (only the diagram keyword).
info showInfo
Same output; showInfo may appear on the same line or the next line.

Example: info

      info

Example: info showInfo

      info showInfo

Equivalent multiline (parser)

The Langium grammar also allows a line break before showInfo:

info
showInfo
